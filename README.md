# ⚛️ lazaloglucafizik (Lazaloğlu'ca Fizik)

Fizik ve matematikteki temel **skaler ve vektörel büyüklükleri** serbest çalışma masasında birbirinin veya diğer formüllerin üzerine sürükleyip bırakarak doğanın kabul gören formüllerini sentezlediğin, dev formül havuzu, canlı Vikipedi makaleleri ve derin fizik sezgisiyle öğrendiğin modern interaktif laboratuvar uygulaması.

---

## 🌟 Öne Çıkan Özellikler

1. **Genişletilmiş Fizik Havuzu (50+ Formül, 35+ Büyüklük):**
   - **7 SI Temel Büyüklük:** Kütle ($m$), Mesafe ($x$), Zaman ($t$), Akım ($I$), Sıcaklık ($T$), Madde Miktarı ($n$), Işık Şiddeti ($I_v$).
   - **Evrensel Sabitler & Vektörler:** Işık Hızı ($c$), Planck Sabiti ($h$), Yerçekimi İvmesi ($\vec{g}$), Yer Değiştirme ($\Delta\vec{x}$).
   - **Mekanik & Kinematik:** $v = x/t$, $a = v/t$, $F = ma$, $G = mg$, $W = F \cdot x$, $P = W/t$, Hooke Yasası ($F = kx$), Yay Potansiyeli ($E_p = \frac{1}{2}kx^2$).
   - **Dönme Mekaniği:** Açısal hız ($v = \omega r$), Merkezcil ivme ($a_c = \omega v$), Eylemsizlik momenti ($I = mr^2$), Açısal momentum ($L = I\omega$), Tork ($\tau = r \times F$).
   - **Akışkanlar:** Sıvı basıncı ($P = \rho gh$), Arşimet kaldırma kuvveti ($F_k = V \rho g$), Debi ($Q = Av$).
   - **Termodinamik:** İdeal gaz yasası ($PV = nRT$), Molar kütle ($M = m/n$).
   - **Elektromanyetizma:** Yük ($q = It$), Potansiyel ($V = W/q$), Ohm Kanunu ($V = IR$), Güç ($P = VI$), Sığa ($C = q/V$), Manyetik akı ($\Phi = BA$), Faraday İndüksiyonu ($\epsilon = -\Delta\Phi/\Delta t$).
   - **Dalgalar & Optik:** Dalga hızı ($v = \lambda f$), Frekans ($f = 1/T$), Kırılma indisi ($n = c/v$), Aydınlanma şiddeti ($E = I_v / d^2$).
   - **Modern Fizik:** Einstein kütle-enerji ($E = mc^2$), Planck foton enerjisi ($E = hf$), De Broglie dalga boyu ($\lambda = h/p$), Foton momentumu ($p = E/c$).

2. **Serbest Çalışma Masası (Blueprint Dot-Grid Canvas):**
   - Büyüklükleri masaya bırakıp birbirinin üzerine sürükleme.
   - **Formülün üzerine büyüklük bırakarak zincirleme sentezleme** (Örn: $F = ma$ kartına $x$ bırakınca $W = Fx$ oluşur, ona $t$ bırakınca $P = W/t$ oluşur).
   - Manyetik çekim bağı (SVG animasyonlu çizgi) ve anlık reaksiyon önizleme HUD'ı.

3. **Kusursuz KaTeX Matematik Dizgisi:**
   - Tüm formüller kristal netliğinde KaTeX LaTeX motoruyla akademik standartta render edilir.

4. **Canlı Vikipedi & Sezgi Motoru:**
   - Her formül kartında tek tıkla açılan zarif Türkçe Vikipedi yan paneli.
   - Boyut analizi (`[M][L]²[T]⁻²`) ve günlük hayattaki sezgisel karşılıklar.
   - Dileyenler için Google Gemini API entegrasyonu.

## 🚀 Yerel Çalıştırma

Klasördeki `index.html` dosyasına çift tıklayarak tarayıcınızda açabilir veya yerel sunucu başlatabilirsiniz:
```bash
node server.js
```
Ardından tarayıcınızdan **`http://localhost:3000`** adresine gidin.
